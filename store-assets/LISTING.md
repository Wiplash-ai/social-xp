# Social-XP Store Listing

## Name

Social Posting Streak Tracker - Social-XP

## Short Description

Build consistent social posting habits with private, local-only goals, streaks, XP, and progress tracking.

## Long Description

Social-XP turns social publishing into a progression system you can understand at a glance.

Track posts and replies across X, LinkedIn, Threads, Discord, Reddit, Facebook, and Bluesky. The compact on-page widget shows today's XP, streak, level, and remaining goal. The dashboard adds activity trends, network breakdowns, and goal progress without sending your activity to a server.

Features:

- Automatic, best-effort detection of posts and replies
- Daily, weekly, monthly, and yearly goals
- XP, levels, streak bonuses, and overgoal rewards
- Compact widget that stays with you while you post
- Dashboard with trend and network activity views
- Manual correction controls for missed or incorrect activity
- Dark by default with an optional manual light theme
- Local-only browser storage

Social-XP has no account requirement and no backend. Activity counters and preferences stay in your browser.

Tracking depends on the visible interface of supported social sites. When a site changes its composer or labels, a selector update may be required.

## Permission Rationale

### storage

Stores goals, theme preference, activity counters, XP, streak history, and widget position locally in the browser.

### Supported-site host access

Runs the activity detector and optional Social-XP widget only on X, LinkedIn, Threads, Discord, Reddit, Facebook, and Bluesky. Social-XP does not transmit page content or browsing activity.

## Reviewer Steps

1. Install the extension.
2. Set goals on the page that opens after installation.
3. Open a supported social site.
4. Click the Social-XP toolbar icon to display the widget.
5. Publish a test post or reply and confirm the local XP count changes.
6. Open the dashboard from the widget to inspect trends and the correction controls.

No test account or backend is required. Reviewers may use their own account on any supported social site.
